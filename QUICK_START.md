## 📦 Docker Services

### 1. MongoDB
- **Container**: `file-integrity-mongodb`
- **Port**: 27017
- **Data**: Persistent volume storage

### 2. Backend API
- **Container**: `file-integrity-backend`
- **Port**: 8000
- **Features**: Auto-restart, health checks
- **Volumes**: `./storage`, `./logs`

### 3. Frontend (Nginx)
- **Container**: `file-integrity-frontend`
- **Port**: 3000
- **Features**: Static file serving, API proxy, gzip compression
